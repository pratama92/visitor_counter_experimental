# Visitor Counter V2 — Face Recognition Experimental

## Status

**Current state: WORKING EXPERIMENTAL PROTOTYPE — STOP HERE**

The current V2 prototype can:

* Open the camera from the Dashboard `+` button.
* Take a visitor photo.
* Detect faces using Google ML Kit.
* Require exactly **one face**.
* Crop the detected face.
* Resize the face to `112 × 112`.
* Generate a `192`-value face embedding using MobileFaceNet.
* Compare the captured embedding against stored face samples.
* Recognize an existing visitor.
* Register a new visitor with a face embedding.
* Recognize that newly registered visitor later.
* Automatically create **1 visit for 1 recognized face**.
* Return to the Dashboard after creating the visit.

This is an **experimental prototype**, not a production-grade biometric recognition system.

# Face Recognition Pipeline

Current process:

```text
Take Photo
    ↓
ML Kit Face Detection
    ↓
Require exactly 1 face
    ↓
Crop face
    ↓
Square crop
    ↓
Resize to 112 × 112
    ↓
RGB / 255
    ↓
MobileFaceNet
    ↓
192-value embedding
    ↓
Compare against stored embeddings
    ↓
Find highest similarity
    ↓
Existing Visitor OR New Visitor
```

Input:

```text
112 × 112 × 3
```

Output:

```text
192 values
```

The generated embedding has a norm approximately equal to `1`, meaning the dot product is effectively being used as cosine similarity.

# Recognition Threshold

Current experimental threshold:

```dart
const matchThreshold = 0.80;
```

Current behavior:

```text
similarity >= 0.80
    → Existing visitor

similarity < 0.80
    → Treat as new visitor
```

The threshold is intentionally experimental.

We are **not optimizing the threshold or camera pipeline right now**.

The user accepts that camera conditions can influence similarity scores.

# Visit Creation

Business rule:

## 1 Face = 1 Visit

When an existing visitor is recognized and the user confirms:

```text
Recognized visitor
    ↓
Confirm
    ↓
Create exactly 1 visit
    ↓
Return to Dashboard
```

Current visit creation uses the existing application settings.

Current logic:

```dart
final settings = await AppDatabase.instance.getSettings();

final sessionTime =
    (settings['session_time'] as num).toDouble();

final sessionCost =
    (settings['session_cost'] as num).toInt();

final startTime = DateTime.now();

final endTime = startTime.add(
  Duration(
    minutes: (sessionTime * 60).round(),
  ),
);

final visitId = await AppDatabase.instance.insertVisit(
  counter: 1,
  startTime: startTime,
  endTime: endTime,
  sessionCost: sessionCost,
);
```

Therefore:

```text
counter = 1
startTime = current time
endTime = current time + configured session duration
sessionCost = configured session cost
```

